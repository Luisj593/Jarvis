# JARVIS Android

Versión inicial de Android. El prototipo incluye entrada y salida por voz; todavía no se conecta al cerebro de IA ni a otros proyectos.

**Aviso:** repositorio público; no añadir secretos, credenciales ni información privada.

Para compilar: GitHub Actions → Compilar APK JARVIS → Artifacts. La APK de depuración es experimental y no tiene firma de distribución persistente.
